# Abdullah Mohamed — Portfolio (MERN)

The live portfolio of **Abdullah Mohamed**, Software Engineer — Full-Stack (Cairo, Egypt).
One page, one identity: the *field reference* — twin dossier columns around a red key
rail, evidence URLs hung in the margin. Every claim links to a system that answers.

- **Site**: React 18 + Vite client (`apps/client`)
- **API**: Node.js + Express REST service (`apps/server`)
- **Data**: MongoDB via Mongoose — profile, skills, projects, contact messages
- **CV**: one-page PDF, ATS-safe, generated by `tools/cv/build_cv.py` (ReportLab)

## Quick start

```sh
npm install                 # install all workspaces

# Full stack with Docker (mongo + seed + api):
docker compose up --build
# then: npm run dev -w apps/client   → http://localhost:5173 (proxies /api → :4011)

# Or point at any MongoDB (Atlas or local):
cp apps/server/.env.example apps/server/.env   # set MONGODB_URI
npm run seed                                  # import content/seed.json
npm run dev                                   # api :4011 + web :5173
```

## How content works

`content/seed.json` is the single source of truth. The seed script upserts it into
MongoDB; the Express API serves it at `/api/profile`, `/api/skills`, `/api/projects`.
The client reads the same seed at build time, so the static deploy never depends on a
server; when `VITE_API_URL` is set at build time the debrief grows a message form that
persists contact messages to MongoDB via `POST /api/messages` (rate-limited, validated).

## Deployment

- **Client**: GitHub Actions builds `apps/client` and publishes to GitHub Pages
  (`.github/workflows/deploy.yml`).
- **API**: `apps/server/Dockerfile` + `docker-compose.yml` run anywhere containers run
  (Render, Railway, Fly, your own box). Set `MONGODB_URI` and `CORS_ORIGIN`.

## Regenerate the CV

```sh
python3 tools/cv/build_cv.py     # → apps/client/public/Abdullah-Mohamed-CV.pdf
```

## Layout

```
apps/client    React + Vite client (the site)
apps/server    Express API + Mongoose models + seed script
content        seed.json — the single content source
tools/cv       CV PDF generator
```
